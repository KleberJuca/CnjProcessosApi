# Termos de Uso (Resumo) – API Pública do DataJud (CNJ)

Este projeto segue integralmente o Termo de Uso da API Pública do DataJud do CNJ (versão 1.1). Abaixo, um resumo das cláusulas chave. Leia o documento oficial para detalhes completos:

Link oficial: https://datajud-wiki.cnj.jus.br/api-publica/termo-de-uso

1.2 – Aceitação tácita
- O uso da API implica aceitação integral do Termo de Uso.

3.2 – Responsabilidade do usuário
- O usuário se responsabiliza pelo uso da interface e por qualquer informação derivada.

3.3 – Uso não comercial
- Uso exclusivamente legal, não comercial e autorizado. Uso indevido, abusivo, ilegal, malicioso ou imoral é proibido.

3.6 – Dados “as is”
- O CNJ não garante precisão, integridade ou atualidade dos dados fornecidos.

3.8 – Proibição de exploração comercial
- O usuário não deve modificar, distribuir, vender ou explorar comercialmente a API ou qualquer informação derivada.

3.9 – Comunicação ao CNJ
- O usuário concorda em dar ciência ao CNJ de qualquer publicação, estudo, relatório ou documento disponibilizado ao público em geral que utilize dados da API.

3.13 – Limites de requisições
- Limite de 120 requisições por minuto por IP. Esta aplicação aplica rate limiting para facilitar conformidade.

3.19 – Tratamento de sigilo
- Processos com acesso restrito devem retornar erro sem vazamento de informações.

LGPD – Proteção de dados pessoais
- Não armazenamos dados pessoais sensíveis. Metadados públicos podem ser cacheados e descrições são anonimizadas (máscara de CPFs/CNPJs).

Aviso
- Este projeto é open-source (licença MIT) e gratuito, sem exploração comercial dos dados do DataJud. Ao usar, você concorda com estes termos e com o Termo de Uso oficial do CNJ.
